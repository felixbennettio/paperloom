织卷是以文献为中心的科研工作台：收集文献、阅读批注、记笔记，写作时随手引用。每篇文献的 PDF、批注、笔记和手绘都挂在同一条记录下，点一下就能互相跳转。

收集
• 输入 DOI、arXiv 编号、PubMed 编号或 ISBN 即可添加文献，题名、作者、期刊等信息自动补全。
• 拖入 PDF，织卷会从前几页识别出是哪篇文献，扫描件也可以。
• 同时检索 Crossref、OpenAlex、arXiv、PubMed、Semantic Scholar 以及美国国会图书馆等图书馆目录，结果直接入库。
• 导入 RIS、BibTeX、EndNote XML、PubMed、Web of Science 文件，也可以从“文件”、邮件等应用里直接用织卷打开。

阅读
• 流畅的 PDF 阅读器：高亮、下划线、批注、手写、形状、文本框、图章和签名，批注列表就在页面旁边。
• “识别文字”在本机把扫描页变成可搜索、可选取的文字。
• 全文搜索同时查找所有文献的全文、笔记和批注。

思考与写作
• Markdown 笔记：实时预览、[[双向链接]]、反向链接、标签、模板和关系图谱。
• 思维导图、支持 Apple Pencil 的手绘页和制图，可以插入笔记，也可以单独使用。
• 用你自己的 API 密钥向 AI 提问单篇文献或整个文献库，回答附带出处。

引用
• 按 GB/T 7714、APA、IEEE、Chicago、MLA 等格式复制引文或参考文献表。
• 在 Word 文档中引用：在 .docx 或 .odt 里写 [@key] 标记，得到带格式化引文和参考文献表的副本。

数据由你掌控
• 文献库和笔记保存在你的设备上，可同步、备份到你选择的 iCloud、WebDAV、S3 或 Seafile。
• 没有广告，没有统计，不做跟踪。

兼容你熟悉的工具
• 在沙盒中运行许多 Obsidian 和 Zotero 7 插件。
• 文献和笔记支持聚焦搜索、快捷指令和接力。

支持简体中文、繁體中文、English、Français、日本語、Русский。
