## Paperloom · 织卷 0.1.0 — Alpha

第一个 Alpha 版本，完整打通了“检索 → 入库 → 阅读批注 → 笔记 → 引用”这条主线。

**文献库**
- 多级分类、彩色标签、星标、阅读状态（未读 / 在读 / 已读完）、废纸篓（恢复、永久删除、清空）
- 编辑条目的全部字段；表格可按标题、作者、年份、添加日期排序
- 粘贴 DOI、arXiv ID、PubMed ID 或 ISBN，自动补全全部信息

**检索**
- 在线检索 Crossref、OpenAlex、arXiv、PubMed、Semantic Scholar，标出“已在库中”，可批量入库
- 全文搜索：一次搜遍标题摘要、PDF 正文、批注和笔记，中文按词切分（jieba）；结果直接跳到所在的 PDF 页、批注或笔记

**导入导出**
- 导入 RIS、EndNote（知网 / 万方 / 维普导出）、BibTeX、CSL-JSON、PubMed MEDLINE（.nbib）、Web of Science 纯文本、Scopus CSV、EndNote XML；格式自动识别，按 DOI 查重
- 导出 RIS、EndNote、BibTeX、CSL-JSON；18 种引用格式（GB/T 7714 排第一）

**PDF**
- 添加 PDF 时按 DOI、arXiv 编号或标题自动识别并补全信息
- 阅读与批注：5 色高亮、下划线、删除线、查找、缩放、双页、夜间模式、目录；批注列表（跳转、评论、删除）
- 批注保存在文献库里，所有设备、所有平台显示一致

**笔记（Markdown 知识库）**
- 笔记就是普通的 `.md` 文件，可以直接打开现有的 Obsidian 库
- 实时预览、源码、阅读三种模式；文字颜色和背景色
- `[[双链]]` 自动补全，改名时全库同步更新；反向链接和“未链接的提及”；大纲；快速切换（⌘/Ctrl O）
- 与文献打通：`[[@文献]]` 链接到条目，把 PDF 高亮嵌入笔记（点击回到原页），一键生成文献笔记（元数据、摘要、全部高亮）

**其他**
- 界面支持简体中文、繁體中文、English、Français、日本語、Русский
- Paperloom 账号登录（为后续官方同步做准备）
