## Paperloom · 织卷 0.0.1 — 基础框架预览 / Foundation preview

这是第一个预览版本，用来验证全平台的构建、签名和发布流程，功能还很少。

**可以做的**
- 新建文献库分类（支持多级），手动添加文献；DOI 会自动校验并规范化，同一 DOI 不会重复添加
- 工作区布局：水平标签页，或垂直标签页（放左侧或右侧）；Markdown 笔记面板可停靠在左侧或右侧，支持编辑与阅读两种视图
- 界面语言：简体中文、繁體中文、English、Français、日本語、Русский
- Apple 端界面采用 Liquid Glass

**接下来（0.1）**：按 DOI 自动补全、PDF 导入与阅读批注、导入 RIS/BibTeX/EndNote/知网导出文件、在线检索、GB/T 7714 等引用格式导出。

First preview, built to prove the build, signing and release pipeline on every platform. Collections, adding items by hand with DOI validation, horizontal or vertical (left/right) tabs, a dockable Markdown notes panel, and six interface languages.
