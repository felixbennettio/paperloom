## Paperloom · 织卷 0.0.2 — 添加、引用、导入导出 / Add, cite, import and export

**新功能**
- **按标识符添加文献**：粘贴 DOI、arXiv ID、PubMed ID 或 ISBN，自动补全标题、作者、期刊、卷期页、摘要等全部字段；同一 DOI 不会重复入库
- **文献详情页**：显示全部字段，DOI 可直接打开
- **引用格式**：内置 18 种样式，GB/T 7714（顺序编码制 / 著者-出版年制）排在最前，另有 APA、MLA、Chicago、IEEE、Vancouver、Nature 等；参考文献条目和文中引注都可一键复制
- **导入**：RIS（Web of Science、Scopus、PubMed 等）、EndNote 标签格式（知网、万方、维普导出）、BibTeX / BibLaTeX、CSL-JSON；格式自动识别，兼容 GB18030 编码的旧版知网导出文件；导入时会跳过库中已有的 DOI，并给出汇总
- **导出**：把当前列表导出为 RIS、EndNote、BibTeX 或 CSL-JSON，自动生成引用键
- **Paperloom 账号**：可以登录（为后续官方同步做准备）；Apple 端令牌存放在钥匙串中

**修复**
- Windows 安装包构建不再卡在 Rust 工具链下载

**New:** add papers by DOI, arXiv ID, PubMed ID or ISBN with every field filled in; an item detail page; citations and reference lists in 18 styles with GB/T 7714 first; import of RIS, EndNote tagged (CNKI, Wanfang, VIP), BibTeX and CSL-JSON files (GB18030 too), skipping DOIs already in the library; export to the same formats; signing in to a Paperloom account.
